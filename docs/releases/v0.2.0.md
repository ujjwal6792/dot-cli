# dot v0.2.0

Dot is now a Rust + Ratatui workspace backed by native chezmoi and system Git.

- Persistent Status, Files, Git, Machines, Details and Activity sections, each with
  visible tabs. `[` and `]` switch tabs in the focused section; mouse clicks use
  the same controls. Section labels and numbers are lavender; active tabs are cyan.
- HOME folder browsing includes readable untracked entries, aggregate change
  status, exact file selection and direct initialize/clone/connect setup actions.
- Capture, apply, restore and forget use native chezmoi. Git staging, committing
  and pushing remain explicit and show the real index and repository state.
- Shared, OS and hostname settings use native chezmoi data and templates.
- Reviewed operations include freshness checks, serialized writes, backups,
  partial outcomes and local activity. Automatic synchronization and summary
  reporting are separate local opt-ins.
- Fixes include repeated missing-source errors, blocked quit, startup listings
  requiring navigation, unreadable selection text and inconsistent tab controls.

## Installation and upgrade

Download the archive for your platform and verify it against `SHA256SUMS`. Extract
the complete archive and keep `dot` beside its `libexec/chezmoi`, licenses and
release manifest. Add the extracted directory to PATH or symlink its `dot`.
System Git is required; Rust and Python are build-time tools only.

This replaces the Go implementation and its install/update protocol. Keep a backup
of legacy data before upgrading. `dot migrate OLD_SOURCE NEW_SOURCE` previews
conversion into a new chezmoi source; constrained or ambiguous legacy entries are
held for explicit translation. Connect an ordinary chezmoi source using `dot init
--source /absolute/path`. Initialization does not apply HOME configuration files.

Strict automatic sync supports a conservative regular-file subset. Dynamic source
requires explicit local trust. Advanced Git history operations and hunk staging
remain available through external Git tools.

See [the specification](../rust-rewrite-spec.md), [verification](../rust-acceptance.md)
and [original bug register](../tui-redesign-bugs.md) for implementation details.
