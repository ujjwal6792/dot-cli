# dot v0.2.1

Includes the Rust/Ratatui workspace and distinct section highlights from v0.2.0.

Fixes bundled chezmoi lookup when `dot` is invoked through a symlink. Dot now
resolves its actual executable before locating `libexec/chezmoi`, so the installed
bundle works without a separate system chezmoi installation. A native integration
test reproduces the symlinked executable and version-directory installation layout.

Keep the complete extracted bundle together and verify `SHA256SUMS` before
installation. System Git remains required.
