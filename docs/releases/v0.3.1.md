# dot v0.3.1

Actions now keep their review and result in a centered dialog over the workspace.
Preparing reviews and slow background work show a bottom-right toast; visible
toasts stay for at least 0.8 seconds. Enter and `y` both confirm reviews and local
action confirmations.

Tree-sitter syntax highlighting is bundled for file previews, source editing, and
review/Git diffs. Supported formats include shell startup files, TOML, JSON/JSONC,
YAML, INI (including Git and Ghostty config), Lua, Python, Rust, JavaScript/JSX,
and TypeScript/TSX. Chezmoi filenames and template suffixes are recognized.
Highlights are cached, diff markers remain visible, and unsupported or oversized
files fall back to readable text.

Recovery also removes newly created ignore files consistently across directory
orders, and terminal checks wait for a refused background-busy action to become
available before retrying its preparation shortcut.

## File shortcuts

- `r` removes saved copies from dot and keeps original files on disk.
- `R` restores originals from saved configuration.
- `d` or Delete moves untracked originals to system Trash after exact-path review.
  Folders include their contents; links move only the link. Managed files and
  folders containing managed files are refused. Changed contents invalidate a
  review, and failed batches report skipped items. Recover originals through
  system Trash.
- Ctrl+R refreshes the workspace.

Setup adds editable developer ignore defaults to chezmoi and Git. A single
reviewed Ignore action updates both tools while preserving original files and
unrelated staged changes. The welcome guide explains the workflow, and empty
untracked removals show a compact explanation.

Native release builds run formatting, Clippy, integration tests, and terminal
smoke checks on macOS ARM64, Linux x86-64, and Linux ARM64. Each bundle includes
chezmoi v2.73.1. Verify `SHA256SUMS` and keep the complete extracted bundle together;
system Git remains required.
