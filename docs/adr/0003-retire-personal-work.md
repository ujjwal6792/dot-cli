# Machine identity replaces personal/work tags

The single-owner personal/work tag could not describe generic users or two
machines with different adoption choices. Spec #10 removes its flag, tracker field
and template prompt without migration; immutable adoption-v3 machine identity owns
local truth instead. Named manifest profiles remain composable entry lists, not a
renamed personal/work bucket. Legacy group scopes require explicit backup-first
replacement rather than guessed authority.
